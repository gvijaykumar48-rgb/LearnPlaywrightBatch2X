# Learn Playwright Batch 2X

This repository contains tutorials and examples for learning Playwright automation testing with JavaScript.

## Structure

- `chapter_01_Basics/` - Basic Playwright concepts
- `chapter_02_javascript_concepts/` - JavaScript fundamentals relevant to Playwright

## Getting Started

1. Install Node.js and npm
2. Clone this repository
3. Run `npm install` to install dependencies
4. Follow the chapters in order

## Prerequisites

- Node.js (version 14 or higher)
- Basic knowledge of JavaScript
